# OrientationJ Test Images

20 grayscale 2D images for testing and benchmarking orientation analysis: **8 real** images, **8 synthetic** images, whose orientation is known by construction, and **4 compositions** of rings, ramp and noise at four levels of degradation, the test image of the [structure vs nematic](https://Biomedical-Imaging-Group.github.io/OrientationJ/assessment/structure-nematic/) assessment. Each image comes with a binary mask of its meaningful structures.

<p class="oj-center"><a href="../docs/assets/test-images/montage.jpg"><img src="../docs/assets/test-images/montage.jpg" alt="The twenty test images" width="620"></a></p>

**The description of every image, with its mask and the maps that OrientationJ computes on it, is on the documentation page [Test images](https://Biomedical-Imaging-Group.github.io/OrientationJ/test-images/).**

The folder holds:

- `images/` — the 20 source images, TIFF. The synthetic images and the compositions are 32-bit float in [0, 1], named `synthetic_<name>_<size>.tif` and `composition_<name>_<size>.tif`.
- `masks/` — the 20 binary masks, 8-bit TIFF (0 / 255), under the same file names: the pixels whose gradient energy exceeds 0.5% of its maximum, or the analytic annulus for the compositions.
- `code/` — [synthetic_images_2D.ipynb](code/synthetic_images_2D.ipynb) generates the synthetic images and the compositions with the generators of [synthetic_images_2D.py](code/synthetic_images_2D.py); [masks_2D.ipynb](code/masks_2D.ipynb) builds the masks; [macro-maps.ijm](code/macro-maps.ijm) computes with the plugin the feature maps (orientation, coherency, energy, 32-bit TIFF) of every image into `results/maps/`, which is not tracked; [make_montage.py](code/make_montage.py) draws the montage above.
