# Use cases

Since 2013, OrientationJ has been used in **304 peer-reviewed publications**, in 194 distinct fields of application, using 61 different combinations of its commands. The reference table below lists every one of them, with the sentence from the paper describing how the plugin was used and which command it relied on — a table you can sort by year, field or mode, and search.

[Open the reference table](literature.html){ .oj-button }

The fields that recur most tell what the measurement is good for: the actin cytoskeleton (37 papers), collagen and the extracellular matrix in tumors (27), materials and nanofibers (27), cardiac tissue engineering (10), bone and mineralized tissue (5).

Beside the table, these pages collect what surrounds the plugin: the [primary references](references.md) to cite, the [official software and web resources](resources.md), the [community discussions](community.md) where its use and interpretation are debated, and the [related tools](tools.md) it is compared with.
