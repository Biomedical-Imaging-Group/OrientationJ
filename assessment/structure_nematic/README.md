# Structure vs nematic

The structure tensor against the nematic tensor and the naive mean of angles: three local orientation estimators from the same gradient and the same window, measured against an analytic reference on a saturated-ring image under saturation, ramp, noise and window size.

**Read it here: [Structure vs nematic](https://Biomedical-Imaging-Group.github.io/OrientationJ/assessment/structure-nematic/).** This folder holds `ring_experiment_lib.py`, the two notebooks that produce the figures, and the test images.
