# Releases

The plugin, one jar per version. Copy the one you want into the `plugins` folder of ImageJ and restart; on Fiji the BIG-EPFL update site delivers the latest one.

| version | date | jar |
|---|---|---|
| 2.2.0 | 27 September 2026 | [OrientationJ_-2.2.0.jar](OrientationJ_-2.2.0.jar) |
| 2.1.0 | 6 August 2026 | [OrientationJ_-2.1.0.jar](OrientationJ_-2.1.0.jar) |
| 2.0.8 | 24 July 2026 | [OrientationJ_-2.0.8.jar](OrientationJ_-2.0.8.jar) |

The release notes of every version are in the [installation page](https://Biomedical-Imaging-Group.github.io/OrientationJ/installation/#version-history). Older versions are on the [ImageJ update site](https://sites.imagej.net/BIG-EPFL/plugins/). Each jar is built from the tagged source with `mvn package`.
